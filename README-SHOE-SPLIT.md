# 신발 공동 구매 앱 (Shoe Split Purchase App)

## 프로젝트 개요

1+1 할인 혜택을 받기 위해 근처 사용자와 함께 신발을 구매하고 비용을 나누는 모바일 웹 애플리케이션입니다.

## 주요 기능

### 1. 매장 찾기
- 1+1 할인(두 번째 신발 50% 할인)을 제공하는 신발 매장 목록 표시
- 거리별 필터링 (1km 이내, 1-2km, 2km 이상)
- 각 매장의 위치, 거리, 대기 중인 사용자 수 표시

### 2. 파트너 매칭
- 같은 매장에서 구매를 원하는 다른 사용자와 매칭
- 사용자 프로필 정보:
  - 평점 및 완료한 거래 수
  - 선호 사이즈 및 관심 브랜드
  - 도착 예정 시간
- 실시간 매칭 요청 및 수락

### 3. 비용 계산
- 할인 적용 후 총 비용 자동 계산
- 각자 부담할 금액 (50%) 표시
- 정상가 대비 절약액 계산
- 투명한 비용 분할 내역 제공

## 기술 스택

- **프론트엔드**: React 16.11.0
- **상태 관리**: Redux
- **스타일링**: styled-components
- **빌드 도구**: react-scripts

## 사용 예시

### 시나리오
1. 사용자가 신발을 구매하고 싶지만 혼자서는 두 켤레가 필요하지 않음
2. 앱에서 근처의 1+1 할인 매장을 검색
3. 해당 매장에서 구매를 원하는 다른 사용자와 매칭
4. 함께 구매하여 각자 한 켤레씩 받고 비용을 반으로 나눔
5. 정상가보다 저렴하게 신발 구매 완료!

### 절약 계산 예시
- 첫 번째 신발: 100,000원
- 두 번째 신발: 100,000원 → 50% 할인 = 50,000원
- **총 비용**: 150,000원
- **각자 부담**: 75,000원
- **절약액**: 25,000원 (25% 할인)

## 프로젝트 구조

```
├── components/
│   ├── ShoeSplitPurchaseApp.js  # 메인 앱 컴포넌트

│   ├── PurchaseMatch.js          # 파트너 매칭 컴포넌트

├── App.css                       # 글로벌 스타일
└── index.js                      # 앱 진입점
```

## 향후 개선 사항

1. **실시간 통신**: WebSocket을 사용한 실시간 매칭
2. **위치 기반 서비스**: GPS를 활용한 정확한 거리 계산
3. **결제 시스템**: 실제 결제 기능 통합
4. **채팅 기능**: 매칭된 사용자 간 채팅
5. **리뷰 시스템**: 거래 후 상호 평가
6. **알림 기능**: 매칭 요청 및 구매 완료 알림
7. **다국어 지원**: 영어 및 기타 언어 지원
8. **모바일 앱**: React Native를 사용한 네이티브 앱 개발
